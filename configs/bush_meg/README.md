# Bush MEG dataset recipe

This directory contains a declarative recipe for the MEG dataset conventions
that previously belonged to PyMEGDec.  The goal is to make the dataset adapter
reviewable and eventually consumable by a NeuRepTrace `decode-from-config`
workflow, without retaining a separate PyMEGDec package for path and metadata
bookkeeping.

The recipe deliberately uses JSON rather than YAML.  NeuRepTrace already uses
the Python standard-library `json` module in its CLI workflows, whereas YAML
would require an additional dependency.  A YAML loader can be added later as a
thin convenience layer.

## Files

- `dataset.json` describes raw participant file templates, MATLAB/FieldTrip
  field names, metadata columns, preprocessing defaults, and output locations.
- `stimulus_decoding.json` describes the default time-resolved stimulus
  decoding workflow to run once the raw MATLAB files have been converted to MNE
  Epochs or to NeuRepTrace feature matrices.

## Migration intent

The split should be:

```text
PyMEGDec hard-coded dataset assumptions
    -> configs/bush_meg/*.json

PyMEGDec MATLAB/FieldTrip parsing and CTF geometry conversion
    -> neureptrace.io.fieldtrip_mat and related generic adapters

PyMEGDec decoding scripts
    -> neureptrace workflows that accept this recipe

PyMEGDec paper-only alpha/reaction-time analyses
    -> examples, archived reproducibility scripts, or a paper repository
```

## Expected follow-up implementation

The configuration is intentionally explicit enough for a future loader to:

1. expand participant file templates such as `Part{participant}Data.mat`;
2. read MATLAB/FieldTrip fields from the configured struct names;
3. validate trial, time, label, sensor-geometry, and metadata dimensions;
4. create MNE Epochs or NeuRepTrace feature matrices;
5. attach metadata columns from `trialinfo` or an external table;
6. pass the resulting epochs and metadata to existing NeuRepTrace decoding
   commands.

Until that implementation exists, this directory should be treated as the
single source of truth for the dataset-specific assumptions that are being
removed from PyMEGDec.

## Example translation to the existing CLI

After conversion to MNE Epochs, the decoding recipe corresponds roughly to:

```bash
neureptrace-mne-time-decode \
  --epochs results/bush_meg/epochs/sub-01_epo.fif \
  --metadata-csv results/bush_meg/metadata/sub-01_trials.csv \
  --label-column stimulus_class \
  --group-column participant \
  --out results/bush_meg/stimulus_time_decode.csv \
  --observations-out results/bush_meg/stimulus_observations.csv
```

The exact command should be generated by the future config workflow rather than
hand-maintained in analysis scripts.
